# 🎵 Mood Music Recommender

A Streamlit web app that reads how you're feeling in plain English, detects your mood with a small machine-learning model, and finds matching songs on Spotify, filtered by language, genre and favorite artist.

## Features

- **Mood detection from free text.** Type something like *"I feel lonely and want something emotional"* and the model predicts one of six moods: happy, sad, angry, calm, romantic, energetic.
- **Confidence-aware.** The app shows how confident the prediction is and asks for more detail when the input is too vague, instead of guessing.
- **Personalized search.** Combine the detected mood with a language (English, Japanese, Korean, Hindi), a genre (Pop, Rock, Hip Hop, Lofi, Jazz, Classical, Anime, K-Pop) and an optional favorite artist.
- **Up to 10 tracks** with album art and a direct "Listen on Spotify" link.
- **Fast and cheap to run.** The model and Spotify client are cached, and search results are cached for an hour to limit API calls.

## How it works

```
User text ──► TF-IDF (character n-grams) ──► Multinomial Naive Bayes ──► mood + confidence
                                                                            │
        mood keywords + genre + language + artist ──► Spotify search ◄──────┘
                                                            │
                                                     Track cards in the UI
```

For example, "I feel lonely" is classified as **sad**, which builds a search query like `sad emotional calm Lofi English`.

## Getting started

### 1. Clone and install

```bash
git clone https://github.com/Ankitha-Kulkarni/Mood-Music-recommender.git
cd Mood-Music-recommender

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

### 2. Get Spotify credentials

1. Go to the [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) and create an app.
2. Copy the **Client ID** and **Client Secret**.
3. Copy `.env.example` to `.env` and fill in your values:

```
SPOTIFY_CLIENT_ID=your_client_id_here
SPOTIFY_CLIENT_SECRET=your_client_secret_here
```

> **Never commit `.env` or paste your secret into code.** It is listed in `.gitignore`. If a secret is ever exposed, rotate it in the Spotify dashboard right away.

### 3. (Optional) Train the model

A trained model is included, but you can regenerate it any time:

```bash
python train_model.py
```

This prints the cross-validated accuracy and saves `mood_model.joblib`. If the saved model is missing or was built with a different scikit-learn version, the app simply retrains in memory on startup (it takes under a second), so you don't need to worry about version mismatches.

### 4. Run the app

```bash
streamlit run app.py
```

Open <http://localhost:8501>.

## Deployment (Streamlit Community Cloud)

1. Push this repo to GitHub (make sure `.env` is **not** committed).
2. Sign in at [share.streamlit.io](https://share.streamlit.io), click **New app**, and select this repo with `app.py` as the entry point.
3. Open **Settings → Secrets** and add:

```toml
SPOTIFY_CLIENT_ID = "your_client_id_here"
SPOTIFY_CLIENT_SECRET = "your_client_secret_here"
```

4. Deploy. The app reads secrets from the environment locally and from `st.secrets` when hosted.

> Streamlit needs a long-running server, so it won't run on serverless platforms like Vercel. Streamlit Community Cloud, Hugging Face Spaces and Render all work.

## Model details and limitations

- **Training data:** 96 hand-written sentences, 16 for each of the six moods (see `train_model.py`).
- **Accuracy:** about **45%** cross-validated across six classes (random guessing would be about 17%). Common phrasings work well; unusual wording can be misclassified, which is why the app reports confidence and asks for more detail when it is below 50%.
- **Why it's limited:** the bottleneck is the amount of training data, not the algorithm. Several model configurations plateaued in the same range.
- **English only:** the mood classifier understands English text, even though the song search supports several languages.

### Improving the model

- Add more example sentences per mood in `train_model.py` (around 50 per mood is a good target) and re-run it.
- Train on a public labeled emotion dataset such as [`dair-ai/emotion`](https://huggingface.co/datasets/dair-ai/emotion) and map its labels to this app's moods.
- Try a pretrained transformer for emotion classification.
